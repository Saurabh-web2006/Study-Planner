# ✿ Study Planner — Student Dashboard

A beautiful, aesthetic student productivity dashboard built with pure HTML, CSS, and JavaScript.

## 🌸 Features

- **📅 Interactive Calendar** — Navigate months, click any date to add colour-coded events
- **✅ Habit Tracker** — Add weekly habits and mark daily completions
- **📚 Subject Progress** — Track chapter-wise progress for each subject with a visual bar
- **💬 Motivation Hub** — Get inspiring quotes with a single click
- **🔐 Login / Signup System** — Simple auth with localStorage persistence
- **🔍 Expandable Cards** — Click any card to view it in a full-screen modal

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Structure & layout |
| CSS3 | Styling, animations, responsive design |
| Vanilla JavaScript | Logic, DOM manipulation, localStorage |

> No frameworks. No libraries. No build tools. Just pure frontend. ✿

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Saurabh-web2006/Study-Planner.git
   ```
2. Open the folder and double-click `index.html` — that's it! No server needed.
